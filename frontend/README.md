# Frontend — Candidaturas

Angular 18 (componentes standalone) + Angular Material.

```bash
npm install
npm start        # http://localhost:4200 (proxy de /api para http://localhost:8080)
npm run build    # saída em dist/frontend/browser
```

Requer Node 18.19+ (recomendado Node 20). Veja o README da raiz para rodar o sistema completo.
