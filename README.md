# Candidaturas

Sistema web para acompanhar candidaturas a vagas de emprego (foco em vagas de desenvolvedor Java remotas).

- **Backend:** Java 21 + Spring Boot 3, PostgreSQL (H2 no perfil `dev`), Flyway, springdoc
- **Frontend:** Angular 18 (standalone) + Angular Material
- **Infra:** Docker Compose
